Сборка проекта myDesigner (бывший graph) с помощью gn.

1. Запустить скрипт utils/tconf.py -c {параметр}, в качестве параметра передать debug или release.
2. Запустить саму сборку командой ninja -C out/debug (или out/release) {цель сборки}, в качестве цели сборки можно указать myDesigner или название любого из модулей.

Возможно, придётся руками прописать в args.gn путь до qmake.
