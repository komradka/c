GN сборка в MyDesigner.
myDesigner собирается раздельно по модулям и линкуется в один исполняемый файл myDesigner. 

Что такое модуль в терминах gn?
Модуль - это source_set, все файлы, включённые в него компилируются в один объектник (файл с расширением .o).

Как добавить новый модуль?
1.Определить место в папке src, где будет находиться модуль. Создаём папку, имя может совпадать с именем модуля.
2.Обычный модуль состоит из двух папок - include и src. В src лежат все внутренние файлы модуля, в include - интерфейсные (то есть те, которые будут инклюдиться в другие модули). Важно! в src могут быть не только cpp, но и хедеры, что приветствуется.
3.Создать файл BUILD.gn и files.gni
4.В BUILD.gn примерно следующее:

import("//gn/tools.gni")

import("files.gni")

config("имя_модуля_config") {
  include_dirs = ["include"]
}

component("имя_модуля") {
  _visibility = true

  sources = имя_модуля_sources
  deps = [
    "//src/common:common",
  ]

  include_dirs = ["src"]

  public_configs = [
    ":имя_модуля_config"
  ]
}

Поясним каждое слово: 

component - обёртка для source_set
sources - все файлы, включенные в модуль (хранятся в переменной имя_модуля_sources, записанной в files.gni)
deps - список модулей, от которых зависит данный модуль (модуль А зависит от модуля Б, если в файл из А инклюдится файл из Б)
include_dirs - делаем свои файлы из src видимыми для модуля
public_configs - передаём конфиг, делающий include_dirs для файлов из папки include, это нужно для того, чтобы файлы из include были видны во всех зависимых модулях.
_visibility - специальный флаг, ускоряющий сборку, лучше всегда ставить true

Если нужно создавать moc файлы, добавить следующее:

generate_moc("имя_модуля_moc") {
  sources = workflow_sources
}

в deps добавить ":имя_модуля_moc"

Если нужна зависимость от Qt, добавить слудующее:

configs = [
  "//gn:qt_config"
]

Нельзя инклюдить файлы в обход include_dirs таким образом ../../../filename.h. Если не получается заинклюдить без ../../, надо добавить зависимость (deps). При инклюде путь до файла надо начинать после папки include (в большинстве случаев - это просто название файла).


5.Подправить скрипт update_gn.py, добавив в массив modules свой модуль по аналогии с другими.
6.Сделать tconf и пересобрать myDesigner
